COMPARISON AGENT CONTRACT

PURPOSE
Produce factual comparison of supplier responses against confirmed Customer Requirements.

INPUTS
- Confirmed Requirements
- Supplier Responses/Quotes
- Match Analysis
- Supplier evidence

OUTPUTS
- Per-requirement match state
- Commercial differences
- Technical differences
- Missing data
- Conditions
- Evidence references
- Alerts for unresolved conflicts

READ
Requirements, Supplier Responses, Quotes, evidence.

WRITE
Comparison/Match Analysis and factual summaries.

MUST NOT
- Create supplier scores/rankings.
- Select final supplier for commercial reasons unless an explicit workflow rule requires a factual default.
- Change Customer Requirements.
- Choose final Customer Price.
